# Mad Libs sentences for Super Naughts & Crosses.
#
# How to write one:
#   - Put the sentence on one line, with _ where each blank goes.
#   - Under it, add one line for each blank, in order, listing the words a
#     player can choose for that blank, separated by commas.
#   - Leave an empty line before the next sentence.
#   - Lines starting with # are notes like this one and are ignored.
#
# Example:
#
#   My _ ate a _.
#   grandma, hamster, dentist
#   sandwich, sock, candle
#
# A sentence whose number of word lines doesn't match its number of blanks is
# skipped (the browser console says which). The room's host loads this file
# when they open the page, so reload after editing it.
