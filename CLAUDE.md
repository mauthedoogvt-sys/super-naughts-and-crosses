# Super Naughts & Crosses

## Deploying

The playable site is GitHub Pages, built from the root of `main` on
`origin` (https://mauthedoogvt-sys.github.io/super-naughts-and-crosses/).
The Neocities page (`neocities/index.html`) only frames that site.

- Commit to `main` and push it to `origin main` (`git push origin main`).
  Nothing reaches the live site until it is pushed, so don't leave commits
  sitting unpushed.
- Don't push work to any other branch expecting it to show up in the browser.
- After pushing, Pages takes a minute or so to rebuild. Check the live
  `app.js` before saying a change is live.
